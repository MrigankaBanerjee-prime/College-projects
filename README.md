Smart Personal Expense Tracker

About

Smart Personal Expense Tracker is a Python-based desktop application that helps users manage their daily expenses. It allows users to add, edit, delete, and track expenses, set monthly budgets, import expense details from PDF and Word documents, and generate reports.

Features

- Dashboard to view expense summaries.
- Add, edit, and delete expenses.
- Import expense details from PDF and DOCX files.
- Set and track monthly budgets.
- Generate expense reports with charts.
- Export expense records to CSV.

Technologies Used

- Python
- Tkinter
- SQLite
- Matplotlib

How to Run

1. Install Python 3.

2. Install the required package:
   
   "pip install -r requirements.txt"

3. Run the application:
   
   "python main.py"

Project Structure

- "main.py" – Main application.
- "database.py" – Database operations.
- "document_processor.py" – Document reading and expense extraction.
- "requirements.txt" – Required Python packages.
- "data/" – Stores the database.

Purpose

This project was developed to practise Python programming, GUI development, database management, and file handling.
